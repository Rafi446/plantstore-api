# PlantStore API

RESTful E-Commerce API untuk toko tanaman yang dibangun menggunakan Laravel.

## Description

PlantStore API adalah backend aplikasi e-commerce yang digunakan untuk mengelola produk tanaman, kategori, pengguna, keranjang belanja, pesanan, dan stok produk.

Project ini dibuat sebagai portfolio untuk menunjukkan kemampuan dalam pengembangan backend menggunakan Laravel dan REST API.

## Features

- User registration and login
- Authentication with Laravel Sanctum
- Product management
- Category management
- Shopping cart
- Checkout
- Order management
- Stock management
- Role-based authorization
- Form Request validation
- API Resources
- Feature testing

## Tech Stack

- PHP
- Laravel
- Laravel Sanctum
- MySQL
- Eloquent ORM
- REST API
- Postman
- Git & GitHub
